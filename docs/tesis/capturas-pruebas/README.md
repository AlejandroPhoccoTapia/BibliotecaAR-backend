Muestra los conteos y tiempos tal como aparecen en esas salidas. Las otras capturas insertadas en `../capitulo-iv-pruebas-completo.docx` proceden de `../capturas-interfaces/`. Las leyendas identifican cuáles fueron tomadas del frontend publicado con contenido de prueba y cuál corresponde a la interfaz local con datos ficticios en memoria. Ninguna captura de interfaz se presenta como prueba de persistencia remota o de los casos de implantación pendientes.
