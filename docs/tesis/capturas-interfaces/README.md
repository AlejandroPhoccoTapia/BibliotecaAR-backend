## Procedencia

- `IU-01-*`, `IU-03-*`, `IU-04-detalle-libro.jpg`, `IU-04b-*`, `IU-05*` e `IU-07a-*`: capturas del frontend publicado en Vercel, usando una cuenta y contenido de prueba. Solo se navegó y se abrieron formularios; no se guardó contenido.
- `*-demo.jpg`: capturas de la misma interfaz React ejecutada localmente con `tests/mock-api.mjs`, que entrega datos ficticios en memoria. En esta copia se generó un código ficticio de seis caracteres. Estas capturas muestran la presentación, no validan la persistencia ni el despliegue remoto.

El documento usa las capturas más legibles de ambas fuentes. El directorio conserva algunas vistas alternativas para elegir otra composición. No incluye la fotografía de un estudiante que aparecía en la cuenta del servicio publicado.

Las interfaces móviles IU-09 a IU-17 requieren capturas nuevas de la aplicación Android en un teléfono. Las imágenes de AR enviadas anteriormente en la conversación mostraban versiones previas de la pantalla y no se incluyen como evidencia de la versión actual.
